# manCAD Simulation V2

Elektroschemas zeichnen und simulieren. Offizielle Windows-Downloads von **man-CAD**.

## Herunterladen und installieren

[**Windows-Setup V2 herunterladen (.exe)**](https://github.com/man-CAD/manCAD-Simulation/releases/download/v2.0.0/ManCADSimulation-Setup-2.0.0.exe)

1. Die einzelne Datei **ManCADSimulation-Setup-2.0.0.exe** herunterladen und starten.
2. Die Installation abschliessen.
3. **manCAD Simulation** über die Verknüpfung im Startmenü oder auf dem Desktop öffnen.

Für **Windows 10/11 x64**. Java und JavaFX sind enthalten. Kein manuelles Entpacken und keine separate Java-Installation nötig. Das Setup installiert ohne Administratorrechte im Benutzerordner.

[Änderungen und weitere Release-Dateien](https://github.com/man-CAD/manCAD-Simulation/releases/latest)

## Funktionen

- Elektro-Wirkschaltschemas und allpolige Schemas mit 203 Symbolen.
- Simulation von Schaltern, Tastern, Relais, Minuterien, Schaltuhren, Dämmerungsschaltern und Leuchten.
- Projekte als Ordner mit einer Datei pro Zeichnung.
- Elektro-Layouts mit manCAD-Plankopf und Exportfunktionen.
- Leitungen mit geraden Abschnitten: 90° normal, 45° bei gedrückter Tab-Taste.

Eigene Projekte werden separat gespeichert. Zum Übertragen auf einen anderen PC den vollständigen Projektordner kopieren. Die Anleitung wird mit dem Programm installiert.

Die Datei `SETUP-SHA256SUMS.txt` auf der Release-Seite enthält die Prüfsumme der Setup-EXE. Das zusätzliche ZIP und die signierte Update-Beschreibung werden für interne Programmupdates bereitgestellt; für die normale Installation genügt die Setup-EXE.
