# manCAD Simulation

Elektroschemas zeichnen und simulieren. Offizielle Windows-Downloads von **man-CAD**.

## Herunterladen und starten

[**Aktuelle Windows-Version herunterladen**](https://github.com/man-CAD/manCAD-Simulation/releases/latest)

1. Unter **Assets** die Datei `ManCADSimulation-Windows-0.1.0.zip` herunterladen.
2. Die ZIP vollständig entpacken.
3. Im entpackten Ordner `ManCADSimulation.exe` öffnen.

Für **Windows 10/11 x64**. Java und JavaFX sind enthalten; eine separate Java-Installation ist nicht nötig. Die Ordner `app` und `runtime` müssen neben der EXE bleiben.

## Funktionen

- Elektro-Wirkschaltschemas und allpolige Schemas mit 200 Symbolen.
- Simulation von Schaltern, Tastern, Relais, Minuterien, Schaltuhren, Dämmerungsschaltern und Leuchten.
- Projekte als Ordner mit einer Datei pro Zeichnung.
- Elektro-Layouts mit manCAD-Plankopf und Exportfunktionen.
- Leitungen mit geraden Abschnitten: 90° normal, 45° bei gedrückter Tab-Taste.

Eigene Projekte werden separat gespeichert. Zum Übertragen auf einen anderen PC den vollständigen Projektordner kopieren. Die Anleitung liegt der ZIP bei.

Die Datei `SHA256SUMS.txt` auf der Release-Seite enthält die Prüfsumme des Downloads.
